# Crypto Tracker

A React app for following the cryptocurrency market: a live market table for the top 100 coins, 30-day price charts, and a currency converter.

## Features

- **Market table:** Top 100 coins by market cap with price and market data (CoinGecko API)
- **Price charts:** 30-day daily charts for Bitcoin, Ethereum and Dogecoin (Chart.js)
- **Currency converter:** Converts between currencies using the Frankfurter API
- Responsive layout

## Tech Stack

- React
- Chart.js, react-chartjs-2
- Axios
- Ant Design, React Bootstrap
- CoinGecko API, Frankfurter API

## Getting Started

```bash
npm install
npm start
```
